# Agent instructions

## Validation

- Use `biome ci` to validate formatting.
- Use `biome check --write` to fix formatting and linting issues.
- Do not write, add, or restore automated tests in this repository.
- Do not add test frameworks, test-only dependencies, or test scaffolding.
- Validate changes through YAML/configuration review and manual Home Assistant
  verification when available, using automation traces and debug notifications.
